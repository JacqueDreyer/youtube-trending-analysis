# YouTube Trending Analysis

This project analyzes the top 1000 trending YouTube videos using Python.

## ✅ Features

- Cleans raw CSV data from Kaggle
- Extracts and exports top 10 most-viewed videos
- Summarizes total views by category
- Outputs Excel summary and PNG charts

## 📦 Output

- `summary.xlsx`: 3 sheets with cleaned data, top 10, and views by category
- `top_10_views_plot.png`: horizontal bar chart of most viewed videos
- `views_by_category.png`: bar chart of total views by category

## 🛠️ Tools Used

- Python
- pandas
- seaborn / matplotlib
- openpyxl

## ▶️ To Run

```bash
python youtube_analysis.py
